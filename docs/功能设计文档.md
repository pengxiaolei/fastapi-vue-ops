# DevOps平台功能设计文档

## 项目概述
一个简单的DevOps平台，用于管理机器和部署应用。采用FastAPI + Vue技术栈。

---

## 一、机器管理模块

### 1.1 机器基本信息管理
- **机器列表**：分页展示所有机器信息
  - 主机名/IP地址
  - 操作系统（Linux/Windows/macOS）
  - 机器状态（在线/离线/维护中）
  - CPU/内存/磁盘使用率
  - 所属环境（开发/测试/生产）
  - 标签/分组
  - 创建时间/最后心跳时间

- **机器详情**：查看单台机器的详细信息
  - 基本信息（IP、端口、系统版本）
  - 硬件配置（CPU核数、内存大小、磁盘容量）
  - 实时资源监控（CPU、内存、磁盘、网络）
  - 已部署应用列表
  - 操作历史记录

- **机器CRUD操作**
  - 添加机器（手动录入/批量导入）
  - 编辑机器信息
  - 删除机器（软删除）
  - 批量操作（批量删除、批量修改标签）

### 1.2 机器连接与认证
- **SSH连接配置**
  - 用户名密码认证
  - 密钥认证（支持上传公钥/私钥）
  - 端口配置
  - 超时设置

- **连接测试**
  - 测试机器连通性
  - 验证认证信息有效性
  - 显示连接错误详情

- **Agent管理**（可选）
  - Agent安装脚本生成
  - Agent状态监控
  - Agent自动升级

### 1.3 机器分组与标签
- **分组管理**
  - 创建/编辑/删除分组
  - 按环境分组（开发/测试/生产）
  - 按业务线分组
  - 按地域分组

- **标签系统**
  - 自定义标签
  - 按标签筛选机器
  - 标签批量管理

### 1.4 机器监控
- **实时监控**
  - CPU使用率
  - 内存使用率
  - 磁盘使用率
  - 网络流量
  - 系统负载

- **历史监控数据**
  - 监控数据图表展示
  - 自定义时间范围查询
  - 数据导出

- **告警配置**
  - 资源阈值设置
  - 告警通知方式（邮件/钉钉/企业微信）
  - 告警历史记录

## 二、应用管理模块

### 2.1 应用基本信息管理
- **应用列表**
  - 应用名称/标识
  - 应用类型（Web服务/后端服务/定时任务）
  - 当前版本
  - 部署状态
  - 部署机器数量
  - 最近部署时间

- **应用详情**
  - 基本信息
  - 部署配置
  - 部署历史
  - 运行实例列表
  - 访问地址

- **应用CRUD操作**
  - 创建应用
  - 编辑应用信息
  - 删除应用

### 2.2 部署配置管理
- **部署方式**
  - 直接部署（上传压缩包）
  - Git部署（从代码仓库拉取）
  - Docker部署（镜像部署）
  - K8s部署（可选）

- **部署参数配置**
  - 部署路径
  - 启动命令
  - 停止命令
  - 重启命令
  - 健康检查配置
  - 环境变量配置
  - 端口配置

- **文件配置**
  - 配置文件模板管理
  - 配置文件版本管理
  - 不同环境配置区分

### 2.3 部署执行
- **一键部署**
  - 选择部署目标机器
  - 选择部署版本
  - 预览部署变更
  - 执行部署

- **部署策略**
  - 直连部署
  - 蓝绿部署
  - 滚动部署
  - 暂停/继续部署

- **部署过程**
  - 实时部署日志输出
  - 部署进度展示
  - 部署状态跟踪
  - 部署失败自动回滚

### 2.4 部署历史与回滚
- **部署历史记录**
  - 部署时间/操作人员
  - 部署版本
  - 部署机器
  - 部署结果（成功/失败）
  - 部署日志

- **版本回滚**
  - 一键回滚到指定版本
  - 回滚预览
  - 回滚日志记录

## 三、用户与权限模块

### 3.1 用户管理
- 用户列表
- 用户创建/编辑/删除
- 用户状态管理（启用/禁用）
- 密码重置

### 3.2 角色与权限
- 角色管理（超级管理员/管理员/普通用户/只读用户）
- 权限细粒度控制（机器管理/应用部署/查看等）
- 角色权限配置

### 3.3 操作审计
- 操作日志记录
- 操作人/时间/内容
- 操作类型筛选
- 日志导出

## 四、系统设置模块

### 4.1 系统配置
- 基础设置（站点名称、Logo等）
- 安全设置（会话超时、密码策略）
- 通知设置（邮件、钉钉、企业微信配置）

### 4.2 仓库配置
- Git仓库配置
- Docker镜像仓库配置
- 私有源配置

### 4.3 系统监控
- 平台自身运行状态
- 系统资源使用情况
- 任务队列状态

## 五、功能优先级建议

### P0（核心功能，必须实现）
1. 机器基本管理（增删改查）
2. SSH连接与认证
3. 应用基本管理
4. 简单部署功能（上传包部署）
5. 部署日志查看
6. 用户登录与基础权限

### P1（重要功能，建议实现）
1. 机器实时状态监控
2. Git方式部署
3. Docker部署
4. 部署历史与回滚
5. 机器分组与标签
6. 操作审计日志

### P2（增强功能，后续迭代）
1. 高级部署策略（蓝绿、滚动）
2. 告警通知系统
3. 配置中心
4. Agent管理
5. K8s集成
6. CI/CD流水线集成

## 六、技术栈建议

### 后端
- FastAPI - Web框架
- SQLAlchemy - ORM
- Pydantic - 数据验证
- Alembic - 数据库迁移
- Paramiko - SSH连接
- Docker SDK - Docker操作
- Redis - 缓存/任务队列
- Celery - 异步任务

### 前端
- Vue 3 + Vite
- Element Plus / Ant Design Vue - UI组件库
- Pinia - 状态管理
- Vue Router - 路由
- ECharts - 图表展示
- Axios - HTTP客户端

### 数据库
- MySQL / PostgreSQL - 主数据库
- Redis - 缓存/会话存储

### 部署
- Docker + Docker Compose
- Nginx - 反向代理
